Rx Formatador de Exames – Linha Reta

Cole ou carregue os exames → escolha a data → gere a linha pronta para colar na evolução.

Protótipo local em HTML

1 Entrada de exames

Você pode colar o texto dos exames abaixo ou enviar um arquivo .txt. Para PDF/DOC/DOCX, use o texto extraído ou adapte o código com bibliotecas JS (comentários no script).

• .txt já é lido e enviado para a caixa de texto.
• Para PDF/DOC/DOCX, você pode adaptar o código com pdf.js / mammoth.js (veja comentários no JS) ou simplesmente copiar e colar o conteúdo aqui.

2 Saída formatada

Resultado em linha reta, pronto para colar no prontuário.

Este protótipo vem com um conjunto inicial de exames mapeados (hemograma, eletrólitos, função renal/hepática, gaso, parcial de urina etc.).
Para adicionar ou alterar exames, edite o array examDefinitions no script.

⚠️ Importante: o parser é heurístico. Sempre revise o resultado antes de colar na evolução.
